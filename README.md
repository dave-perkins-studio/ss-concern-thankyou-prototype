# Concern Worldwide — thank-you page attribution prototype

A shareable, clickable prototype of Concern's donation thank-you page with the
attribution question moved onto it. Published so it can be sent as a link.

**Live:** https://dave-perkins-studio.github.io/ss-concern-thankyou-prototype/

This repo is **public only to serve the page**. It holds nothing but the built
prototype. The project it belongs to — the brief, the deck, the research, the
QA reports and the decisions journal — stays private in
`dave-perkins-studio/ss-concern-attribution`.

## Not an official Concern build

This is a SystemSeed design prototype. The Concern branding is a reconstruction
made to show the question in its real surroundings; photography and
illustration are placeholders, and the page carries that notice in its footer.
It is marked `noindex, nofollow` so it will not be indexed as Concern's own
page.

## What it demonstrates

The attribution question moved out of the donation form and onto the
confirmation page: one tap, no submit button, no navigation. Answering
collapses the whole block to a single line of thanks, with a quiet
"Change answer" link to recover from a mis-tap. "Any other reason" opens an
optional free-text field after the thanks, so the one-tap path is never
blocked.
